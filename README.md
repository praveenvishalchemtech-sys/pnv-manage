# PNV Manager Pro — Phase 1

React + Vite + TypeScript business manager for PNV TRADERS.

Run: `npm install && npm run dev`

Features: dashboard, two-shop stock, products, sales entry, automatic stock deduction, sales history, JSON backup and restore.

**Important:** Demo inventory is not real business data. Browser localStorage is not a production-grade database. Backup regularly; data does not sync between devices.
