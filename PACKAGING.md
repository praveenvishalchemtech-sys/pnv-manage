# Install PNV Manager Pro

Go to **Actions** on GitHub, select **Windows EXE Installer** or **Android APK**, then **Run workflow**. Once the run succeeds, download its artifact ZIP and extract the EXE or APK.

Windows EXE is unsigned and may trigger SmartScreen. Android APK is a debug build for direct installation, not Play Store distribution.

Existing browser localStorage does not automatically transfer into the installed application. Export a JSON backup from your existing app and restore it inside each new installation. Installed Windows and Android data are separate, with no cross-device synchronization. Do not enter live shop sales independently on multiple devices unless a shared database is added.
